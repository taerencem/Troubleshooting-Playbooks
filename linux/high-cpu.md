# Linux High CPU Playbook

## Symptoms
- Slow server
- High load average

## Quick Checks
- top
- htop

## Deep Checks
- Check services
- Check cron jobs
- Review logs

## Root Causes
- Bad process
- Malware
- Misconfigured service

## Resolution Steps
- Restart service
- Kill process
- Fix configuration

## Preventative Measures
- Monitoring alerts

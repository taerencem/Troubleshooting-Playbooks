# Windows Slow Performance Playbook

## Symptoms
- High CPU
- High RAM
- Slow boot
- Freezing

## Quick Checks
- Task Manager review
- Check disk usage
- Check startup apps

## Deep Checks
- Run SFC /scannow
- Run DISM repair
- Check for malware
- Review event logs

## Root Causes
- Bad updates
- Malware
- Corrupted system files
- Too many startup apps

## Resolution Steps
- Disable startup apps
- Update drivers
- Run repairs
- Remove malware

## Preventative Measures
- Scheduled maintenance
- Endpoint monitoring

# VPN Issues Playbook

## Symptoms
- Cannot connect
- Disconnects frequently
- No access to internal resources

## Quick Checks
- Verify credentials
- Check internet connection
- Restart VPN client

## Deep Checks
- Check VPN gateway logs
- Validate certificate expiration
- Check split-tunnel settings
- Review firewall rules

## Root Causes
- Certificate expired
- Gateway overloaded
- Firewall block
- DNS misconfiguration

## Resolution Steps
- Renew certificate
- Restart gateway
- Fix firewall rules
- Update DNS settings

## Preventative Measures
- Monitor certificate expiration
- Use VPN HA pairs

# M365 Login Failure Playbook

## Symptoms
- Cannot log in
- MFA failures
- “Account not found”

## Quick Checks
- Check password
- Verify MFA device
- Check Azure AD sign-in logs

## Deep Checks
- Check conditional access
- Validate licensing
- Review identity protection alerts

## Root Causes
- MFA misconfiguration
- License removed
- Conditional access block

## Resolution Steps
- Reset MFA
- Reassign license
- Update CA policies

## Preventative Measures
- Monitor sign-in logs
- Document CA policies

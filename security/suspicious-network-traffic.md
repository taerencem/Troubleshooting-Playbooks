# Suspicious Network Traffic Playbook

## Symptoms
- High outbound traffic
- Unknown IP connections
- IDS alerts

## Quick Checks
- netstat / ss
- Check firewall logs
- Review process list

## Deep Checks
- Packet capture
- Analyze traffic patterns
- Check for malware

## Root Causes
- Malware
- Compromised service
- Misconfigured application

## Resolution Steps
- Block IPs
- Kill process
- Remove malware
- Update firewall rules

## Preventative Measures
- Network monitoring
- IDS/IPS

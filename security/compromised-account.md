# Compromised Account Playbook

## Symptoms
- Unexpected MFA prompts
- Suspicious sign-ins
- Unauthorized changes

## Quick Checks
- Reset password
- Revoke sessions
- Check sign-in logs

## Deep Checks
- Review audit logs
- Check mailbox rules (M365)
- Validate CA policies

## Root Causes
- Phishing
- Password reuse
- Token theft

## Resolution Steps
- Reset password
- Enforce MFA
- Remove malicious rules
- Review CA policies

## Preventative Measures
- Conditional access
- Identity protection
